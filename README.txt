# Robot Site (Local Starter)

## Open locally on Windows
1) Unzip this folder
2) Double-click `index.html`

## Add your media
Put your images/videos into `/assets` and keep these filenames:
- hero.jpg
- product.jpg
- demo-1.mp4
- demo-2.mp4
- video-poster-1.jpg
- video-poster-2.jpg
- gallery-1.jpg ... gallery-4.jpg

## Contact form
`contact.html` uses `mailto:` by default.
Change the email in `app.js` (search for pilots@solrobotics.com).
